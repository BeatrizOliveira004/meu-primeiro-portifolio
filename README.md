Meu Primeiro Portfólio

Este projeto foi desenvolvido com o objetivo de praticar os fundamentos do desenvolvimento web e criar minha primeira página de portfólio.

Tecnologias utilizadas

* HTML5
* CSS3

Objetivo

Aprender e aplicar conceitos básicos de estruturação e estilização de páginas web, desenvolvendo minhas habilidades em programação.
